# Backstage

**A conference page built for you. Every decision, explained.**

## Key features

- Scan a QR code and answer five quick questions.
- Discover sessions matched to your interests and experience.
- Get a personal page shaped around your preferences.
- Save sessions and see live interest and engagement trends.
- Search the agent’s decisions, build history and code commits.

## Technologies

- **Elasticsearch:** connects surveys, recommendations, the build queue and the searchable decision history.
- **OpenAI:** integrated for page generation, with validation and a reliable template fallback.
- **Dash0:** traces requests and builds, measures performance and helps investigate failures.
- **Radar:** runs and inspects our Kubernetes services.
- **Gitar · Sonar track:** reviews changes and catches issues before release.

## Why it matters

- **For attendees:** less searching, more relevant sessions.
- **For organizers:** a live picture of what people want.
- **For developers:** evidence behind the agent’s choices.

## Demo scope

- Real Elasticsearch, hosted worker and GitHub publication have been exercised.
- The verified live build uses templates; successful OpenAI page generation is still pending.
- Sessions are synthetic; simulated attendees are labelled. Generated pages are public.
